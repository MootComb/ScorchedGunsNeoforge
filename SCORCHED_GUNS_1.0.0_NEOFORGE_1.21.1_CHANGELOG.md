# Scorched Guns 1.0.0 for NeoForge 1.21.1

## Overview

This release ports Scorched Guns to Minecraft 1.21.1 on NeoForge.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.228 or newer within the supported 1.21.1 range
- Framework 0.13.9 or newer
- Curios 9.4.1 or newer
- GeckoLib 4.8.4 or newer

## Smoke Tested

- Client startup and world loading
- Dedicated server startup
- Multiplayer connection
- Weapon rendering, shooting and reloading
- Third-person one-handed and two-handed weapon poses
- ExoSuit GUI
- Structures, structure loot and supply crates
- Scorched Guns mob spawning
- Basic projectile and machine interaction checks

## Optional Integrations

Optional metadata is present for supported integrations such as JEI, Create, Farmer's Delight, Immersive Engineering, Controllable, Backpacked, Sculk Horde, Valkyrien Skies, Mekanism and PlayerRevive. These mods are not bundled with Scorched Guns.

## Known Non-Blocking Issues

- Beowulf and Gibbs exact bonus-looting restoration remains a follow-up.
- Projectile ping and lag-compensation behavior has a conservative fallback that may need more multiplayer QA.
- Some minor asset or model warnings may still need visual QA.
- Netherite gas mask fire-resistant behavior should receive additional runtime QA.

## Notes

This package is prepared for manual release review. It has not been uploaded by this changelog.
